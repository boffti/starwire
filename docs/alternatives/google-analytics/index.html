8 projects on starwire do the same job. Ranked by how much of what Google Analytics does each one covers, read from its README and website. Ties go to the most active.

What Google Analytics does

  1. Visitor and pageview trackingcore
  2. Traffic sources and referrers
  3. Dashboards and reportscore
  4. Custom events and goals
  5. Funnels and conversion tracking
  6. Real-time view
  7. Audience segments and filters
  8. Data export and API

Each dot in the table is one job, in this order. Square dots are core jobs and count double. Full means yes, half means partly. "See the evidence" under a project shows the line behind each one.
